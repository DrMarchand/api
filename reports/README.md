# Generated reports

Generated audit and recovery reports must not be committed to this public repository when they contain local paths, usernames, hostnames, infrastructure details, or unapproved records.

Store working reports in an access-controlled working lane. Preserve an approved permanent record in 📚 DrMarchand’s ⚛︎ Library™ only after provenance, validation, checksum where applicable, custody receipt, and authorized-human approval.

This directory intentionally contains no generated report data.
